# AGENTS.md

## Architecture
- Static site, published from the repo root (`netlify.toml`: `publish = "."`, no build command). The generated HTML is **committed**: run `python3 scripts/build.py` after editing content or templates and commit the output.
- `scripts/pages.json` is the single source of truth for page content. Page fields: `path, category, category_name, card, title, desc, h1, exprs, exam`, plus optional `intro[]`, `points[]`, `examples[{e,l}]`, `faq[{q,a}]`, `fit{data,model}` (preloads the regression panel), `params{}` (default slider values), `updated`, `trend` (adds the page to the home page's "New for 2025–2026" section), and `disclaimer` (overrides `DISCLAIMERS` in build.py).
- `scripts/check_pages.py` checks required fields. `scripts/test-parser.js` runs the parser tests and compiles every page's equations.
- `assets/js/engine.js` (UMD, `window.EGEngine`): `compileExpr`, `createGraph`, `regress(points, model)`, `parseData(text)`, `MODELS`. Compiled kinds: function (no kind), `implicit`, `ineq`, `parametric`, `polar`, `points`.
- `assets/js/app.js`: the UI, driven by `window.EG_CONFIG` (`exprs, exam, category, fit, params`), which build.py injects on each page.
- `sw.js` is generated (its version follows `ASSET_V`). Pages are network-first and `/assets/*` is cache-first.

- Statistics pages (`"stats": "zscore"|"stddev"|"ci"|"ttest"` in pages.json) do not use the graph engine: `page_stats()` renders a form host and `assets/js/stats.js` builds the UI. They take `intro[]`, `sections[{h,p[],ul[]}]` and `faq[]`. Run `node scripts/test-stats.js` after changing the maths.

## Conventions
- Bump `ASSET_V` in build.py after any CSS or JS change (assets are served `immutable`).
- Page copy uses US spelling and should be factual. Hedge exam-policy claims ("check the current policy") and give every brand or exam page a trademark disclaimer.
- The graph uses one shared scale for both axes, so keep example and regression data in similar x and y ranges (scale money to thousands, for example).
- Points syntax: `(1, 2), (3, 4)`. Components must not use `t` or `x`, otherwise the text is treated as a parametric curve.
- The email form `cheatsheet` is plain static HTML (Netlify Forms with a honeypot `company` field) and posts to `/thanks/`, which links to `/cheat-sheet/` (both are noindex).

## Site search
- `assets/js/search.js` is hand-written; `assets/js/search-data.js` is generated by `build.py` (`search_index()`) from `pages.json`. Do not edit the data file by hand.
- The animated placeholder phrases live in `SEARCH_HINTS` in `build.py`. Keep them short and make sure each one finds a real page.

## 3D page
- `calculus/3d-graphing-calculator/` is rendered by `assets/js/surface3d.js`. `compileSurface` handles `z = f(x, y)`; if it errors, `compileImplicit3` is tried (equation with z, `F - G = 0`) and `EGMarch.tetra` (in `assets/js/marching.js`) extracts the surface. Add `marching.js` before `surface3d.js` on any page that uses the plotter (build.py `page_surface` does this).
- Very large implicit meshes (> 12,000 triangles) also get a coarse copy (`S.meshLow`) that is drawn while dragging. Presets are `[name, formula, optional box half-size]`.
