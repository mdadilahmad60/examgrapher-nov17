# ExamGrapher: free online graphing calculator

ExamGrapher (examgrapher.com) is a fast, free graphing calculator for US students. It has 69 tool landing pages built around how people actually search: exam prep (Digital SAT, digital PSAT, enhanced ACT, AP Precalculus, AP Calculus, Texas STAAR, NY Regents, Smarter Balanced and state tests), algebra, trig, calculus, statistics, data and regression, personal finance, and calculator guides.

## Features
- Graphs functions, implicit equations (circles, conics), shaded inequalities, parametric and polar curves, points and point lists, with sliders for any extra letter.
- Marks roots, intercepts, minimums, maximums and intersections automatically.
- **Data table & regression**: paste spreadsheet data and fit linear, quadratic, cubic, exponential, power or logarithmic models. Shows the equation, r, R² and a prediction box.
- US Exam Mode (locks hints), degree and radian modes, PNG/JPG export, print-to-PDF and share links (`?eq=` + graph title).
- Editable graph title, saved locally per tool page, and used as the export filename.
- **3D plotter** (`calculus/3d-graphing-calculator/`): explicit surfaces `z = f(x, y)` and implicit surfaces such as `x^2 + y^2 + z^2 = 9` (marching tetrahedra), with a colour legend, a flat top view, sliders and PNG export.
- Installable app with offline support (manifest + service worker).
- **Site search**: a large centred search box in the header (a magnifier on phones) with an animated typing placeholder and live suggestions. Press `/` or Ctrl/Cmd+K to focus it.
- Email capture for a test-day cheat sheet (Netlify Forms, form name `cheatsheet`).
- Structured data on every tool page: WebApplication, FAQPage and BreadcrumbList.

## Tech
Plain static HTML/CSS/JS with no framework and no runtime dependencies. Pages are generated by a small Python script from one data file, then hosted on Netlify.

| Path | Purpose |
| --- | --- |
| `scripts/pages.json` | All page content: titles, copy, FAQs, examples, regression presets |
| `scripts/build.py` | Generator: writes every `index.html`, `sitemap.xml`, `robots.txt`, `sw.js`, `404.html` |
| `assets/js/engine.js` | Expression parser, graph renderer and regression maths |
| `assets/js/stats.js` | Statistics tools (z-score, standard deviation, confidence interval, t-test, chi-square): maths plus UI. Pages with `"stats": "<tool>"` in `pages.json` render through `page_stats()` in build.py |
| `assets/js/surface3d.js` | 3D plotter for `calculus/3d-graphing-calculator/` (canvas painter's-algorithm renderer, colour legend, top view; uses `EGEngine.compileSurface` for z = f(x, y) and `EGEngine.compileImplicit3` + `EGMarch.tetra` for F(x, y, z) = 0) |
| `assets/js/marching.js` | Pure marching-tetrahedra surface extraction (`EGMarch.tetra`), no DOM, tested in node |
| `assets/js/search.js` | Header search UI (animated placeholder, suggestions). Loads the generated `assets/js/search-data.js` on first focus |
| `assets/js/app.js` | Calculator UI: equations, keyboard, settings, regression panel |
| `scripts/test-parser.js` | Parser and page-equation tests |
| `scripts/test-surface.js` | Tests the 3D formula parsers and the marching tetrahedra (sphere radius, area, watertight mesh) (`node scripts/test-surface.js`) |
| `scripts/test-stats.js` | Checks the stats maths against SciPy reference values (`node scripts/test-stats.js`) |

## Run locally
```bash
python3 scripts/build.py      # regenerate pages after editing pages.json, build.py or assets
node scripts/test-parser.js   # parser tests (also compiles every page's equations)
python3 -m http.server 8000   # or: netlify dev
```
Bump `ASSET_V` in `scripts/build.py` after any CSS or JS change so browsers and the service worker pick it up.
